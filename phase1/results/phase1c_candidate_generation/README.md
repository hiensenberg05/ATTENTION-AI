# Phase 1C — Candidate Generation

Dataset A only. Candidates combine weak generic signals (gap, app/window change, browser form/navigation, clipboard, and session-relative density shift); none is a boundary rule. The bounded export contains 2,000 representative contexts; aggregate recall/volume is computed across all candidates.
