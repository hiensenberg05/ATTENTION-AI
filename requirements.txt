# ─────────────────────────────────────────────────────────────────────────────
# Attention AI — single dependency set for the whole project
#
# One file, one virtual environment, at the repo root:
#
#     python -m venv venv
#     venv\Scripts\Activate.ps1            # PowerShell
#     pip install -r requirements.txt
#     python -m playwright install chromium
#
# There is deliberately no second requirements.txt and no second venv. Phase 1,
# Phase 2, the backend and the tests all run from this one environment.
#
# Versions are pinned, not ranged. Phase 1's segmentation scorer and Phase 2's
# segments.jsonl are reproducible outputs — they are regenerated and checksummed
# against the committed results, and a silent minor-version bump in numpy or
# scikit-learn is exactly the thing that would break that claim quietly.
# ─────────────────────────────────────────────────────────────────────────────
